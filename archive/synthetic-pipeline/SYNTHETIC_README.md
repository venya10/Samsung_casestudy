# These files are SYNTHETIC. They are not Samsung data.

Every file in this directory is generated by `src/generate_synthetic.py`. No figure
here originates from Samsung, any Samsung agency, or any real measurement. They
exist so the pipeline, models, dashboard and alerting could be built and validated
before real data was available.

**Do not present any number derived from these files as a Samsung result.**

## Why generate rather than wait

Building against real data that has not arrived means either building nothing or
building against assumptions. Generating a dataset to the brief's structure meant
the full system could be built and — more importantly — *verified*, because
generated data has known ground truth. `src/validate_signals.py` asserts that the
cleaning and modelling actually recover what was deliberately planted. That check
is impossible with real data.

## What was deliberately planted

The generator builds one latent truth (spend → adstock → brand equity → sales), then
emits eight partial, inconsistent views of it. Seven signals are planted for the
analysis to find:

| # | Signal | Where |
|---|---|---|
| 1 | Awareness holds through a 55% paid media cut, via carryover plus a paid→influencer/PR mix shift | weeks 24–29 |
| 2 | Four accounts with bought-looking audiences and ~16x the roster median CPA | whole period |
| 3 | Search/Meta cost-per-click inflation of ~43%, which never reverts | weeks 34–44 |
| 4 | Post-launch sentiment collapse from a pricing backlash | weeks 30–33 |
| 5 | Rival A taking share of voice and overtaking Samsung | weeks 38–51 |
| 6 | Egypt: media spend up, unit volume down, driven by an FX-led price rise | weeks 44–49 |
| 7 | Brand equity eroding on a lag after the brand-spend reduction | weeks 42–51 |

## The mess is deliberate too

Clean data would make the cleaning step theatre. These files carry:

- **Four date formats** — `2025-08-04`, `04-08-2025`, `04/08/2025`, `Aug 04, 2025`
- **23 channel spellings** for 7 channels (the taxonomy changed mid-year and nobody backfilled)
- **Three currencies** — AED, SAR, EGP, with sales reported locally
- **Negative spend rows** — agency credit notes, which are real and must be netted, not dropped
- **Exact duplicate rows** in four files
- **Percentages stored as text** — `"43.2%"`, `"12.4%"`
- **Fees stored as formatted text** — `"$1,234.56"`
- **Missing values** in `video_views`
- **Trailing whitespace** in market names
- **Mixed-case tier labels** in the influencer file
- **A monthly brand tracker** against an otherwise weekly grain
- **Two cross-source disagreements** that a real analyst would have to reconcile:
  agency-reported TV spend runs ~3% above finance's, and ad platforms claim ~1.4x
  the revenue the website recorded from paid sessions

## Reproducibility

The generator is seeded (`np.random.default_rng(20260812)`), so re-running produces
byte-identical files. Regenerate with:

```bash
python src/generate_synthetic.py
```

## Replacing with real data

Drop the real files here, then follow "Swapping in real data" in the root README.
`src/ingest.py` is the only module that knows what raw files look like; everything
downstream reads the cleaned weekly model.

Delete this file once the directory holds real data.
